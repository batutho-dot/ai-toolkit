# create-verify

Writes a repo's `verify` script to a fixed contract, so the agent reports PASS or FAIL from a real run.

- **Starts:** By itself, or on request.
- **Files:** `SKILL.md`

## Get it

One file. Open [SKILL.md](SKILL.md) and press "Download raw file", or fetch it straight into
your skills folder:

```bash
curl --create-dirs -o ~/.claude/skills/create-verify/SKILL.md https://raw.githubusercontent.com/batutho-dot/ai-toolkit/main/skills/create-verify/SKILL.md
```

For one project only, use `<project>/.claude/skills/` instead of `~/.claude/skills/`.
Restart Claude Code and type `/` to see the skill listed.

All skills, and how I make them: [../README.md](../README.md).
