# lint

Runs a Markdown wiki's lint script, groups the findings, proposes fixes and applies only the approved ones.

- **Starts:** By itself, or when you type `/lint`.
- **Files:** `SKILL.md`

## Get it

One file. Open [SKILL.md](SKILL.md) and press "Download raw file", or fetch it straight into
your skills folder:

```bash
curl --create-dirs -o ~/.claude/skills/lint/SKILL.md https://raw.githubusercontent.com/batutho-dot/ai-toolkit/main/skills/lint/SKILL.md
```

For one project only, use `<project>/.claude/skills/` instead of `~/.claude/skills/`.
Restart Claude Code and type `/` to see the skill listed.

All skills, and how I make them: [../README.md](../README.md).
