# code-map

Draws a program's steps as a Mermaid diagram, with a table tying every box to `file:line`.

- **Starts:** By itself, on "show me the code".
- **Files:** `SKILL.md`

## Get it

One file. Open [SKILL.md](SKILL.md) and press "Download raw file", or fetch it straight into
your skills folder:

```bash
curl --create-dirs -o ~/.claude/skills/code-map/SKILL.md https://raw.githubusercontent.com/batutho-dot/ai-toolkit/main/skills/code-map/SKILL.md
```

For one project only, use `<project>/.claude/skills/` instead of `~/.claude/skills/`.
Restart Claude Code and type `/` to see the skill listed.
